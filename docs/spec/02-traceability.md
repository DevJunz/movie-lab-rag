## 3. 테스트 결과표 양식

검증 결과 문서(`docs/deliverables/03_검증결과.md`)에 아래 형식으로 채운다. 자동 테스트 결과는 CI의 `reports/junit.xml`에서 옮긴다.

| 검증 ID | 테스트 ID | 수준 | 실행일 | 결과 (통과 / 실패 / 미확인) | 증빙 (CI 실행 링크 · 스크린샷 · 문서) | 비고 |
|---|---|---|---|---|---|---|
| V4.1-1 | TC-F2002-01 | 통합 | | | | |

셀프 체크리스트와 상호 체크리스트도 같은 검증 ID(V4.x-y)를 행으로 쓰고, 열을 "셀프 결과 · 상호 결과 · 점검자"로 둔다.
