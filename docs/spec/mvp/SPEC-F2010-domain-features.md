## 1. 요구사항 원문

> 도메인 특성에 맞는 기능을 1개 이상 설계하고, 근거와 함께 제공한다.

명세서 3장 세부 조건:
- ◆ 도메인의 특성에 맞는 기능을 1개 이상 설계하여 구현해야 한다.
- ◆ 특화 기능도 검색된 문서를 근거로 사용하고, 근거를 함께 제시해야 한다.

## 2. 도메인 표현과 설계 이유 (D-02)

| 기능 | 무엇 | 왜 영화 도메인에 맞나 |
|---|---|---|
| **관람 가이드** | 선택한 영화를 보기 전 · 후에 알아 두면 좋은 배경지식과 관람 포인트를 근거와 함께 정리한다 | 영화는 작품 밖 지식(과학 · 역사 · 원작)을 알면 더 잘 보인다. 위키 문서가 바로 그 지식이다. 평론처럼 보이는 평가 문장은 쓰지 않는다 |
| **사실 여부 판정** | "명량 해전에서 조선 수군은 12척이었다" 같은 주장을 근거로 `사실` · `거짓` · `확인 불가`로 판정한다 | 영화는 각색이 많아 "영화 속 내용이 실제와 같은가"라는 질문이 잦다. 판정 결과가 정해진 라벨이라 검증과 테스트가 쉽다 |

두 기능 모두 **같은 retrieve → generate 그래프**를 쓰고(`task`만 다름), 색인된 문서만 근거로 쓰며, 근거 표시는 SPEC-F2008 형식을 따른다.

## 3. 상세 명세

### 3.1 관람 가이드 (`GuideService.generate(movie_id, on_progress)`)

1. 수집: 질문 대신 고정 문장 `"{제목} ({연도}) 관람 가이드: 제작 배경, 원작 · 실제 사건, 주요 개념, 감독과 출연진"`으로 SPEC-F2004 수집을 실행한다 (캐시 규칙 동일).
2. 그래프: `task="guide"`, `question` = 위 문장. Top-k는 `retrieval.top_k`의 2배(가이드는 여러 측면을 다루므로).
3. 프롬프트 G1:

```text
[작업: 관람 가이드]
너는 {assistant_role}이다. 아래 근거만 사용해 '{제목} ({연도})' 관람 가이드를 쓴다.
형식(소제목 고정, 근거가 없는 소제목은 "문서에서 확인되지 않습니다"라고 쓴다):
## 한 줄 소개
## 알고 보면 좋은 배경
## 관람 포인트
규칙: 모든 문장 끝에 [근거 n]. 근거에 없는 평가 · 추천 · 별점은 쓰지 않는다. 결말을 밝히는 내용은 "스포일러" 표시 후 쓴다.
근거: {근거 블록}
```

4. 결과: `GuideResult{markdown, evidences, cited, uncited}` → 화면에 마크다운 + 근거 목록(F2008).

### 3.2 사실 여부 판정 (`FactCheckService.check(movie_id, claim, on_progress)`)

1. 수집: `claim`을 질문으로 SPEC-F2004 수집을 실행한다.
2. 그래프: `task="factcheck"`, `question = claim`.
3. 프롬프트 C1:

```text
[작업: 사실 판정]
너는 사실 확인 담당이다. 아래 근거만 사용해 주장이 사실인지 판정한다.
- "사실": 근거가 주장을 직접 뒷받침한다.
- "거짓": 근거가 주장과 직접 어긋난다.
- "확인 불가": 근거로 판단할 수 없다.
출력은 JSON 객체 하나만: {"verdict": "사실|거짓|확인 불가", "reason": "판단 이유 (문장마다 [근거 n])", "citations": [n, ...]}
근거: {근거 블록}
주장: {claim}
```

4. 후처리 (코드에서 강제):
   - JSON 파싱 실패 → `verdict = "확인 불가"`, `reason = "판정 결과를 해석하지 못했습니다."`.
   - `verdict`가 세 라벨이 아니면 `확인 불가`.
   - `citations`는 `reason`의 `[근거 n]`과 합친 뒤 범위 밖 번호를 버린다.
   - `verdict`가 `사실` · `거짓`인데 유효한 인용이 0개 → **`확인 불가`로 낮춘다**(근거 없는 판정 금지).
5. 결과: `FactCheckResult{verdict, reason, evidences, cited}` → 화면에 판정 배지 + 이유 + 근거 목록.

### 3.3 화면

- 메뉴 `관람 가이드`: 선택한 영화 기준 `가이드 만들기` 버튼 → 진행 상태(F2012) → 결과.
- 메뉴 `사실 판정`: 주장 입력창 + `판정하기` 버튼 → 진행 상태 → 배지(`사실` 초록 / `거짓` 빨강 / `확인 불가` 회색) + 이유 + 근거.
- 두 결과 모두 영화별로 마지막 결과를 `session_state`에 보관한다(영화 전환 시 섞이지 않음).
