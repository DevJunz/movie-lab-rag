## 1. 한 줄 정의

**Movie Lab**은 사용자가 영화를 고르고 질문하면, 영화 메타데이터와 한국어 위키백과 문서에서 근거를 찾아
`[근거 n]` 번호와 원문 출처를 붙여 답하는 RAG 기반 영화 지식 서비스다.

## 2. 도메인 확정 (명세서 2.1)

명세서 1.2의 도메인 선택 조건 세 가지를 모두 만족한다. 제공 도메인 팩(영화)을 사용한다.

| 조건 | 충족 근거 |
|---|---|
| 항목 메타데이터 약 100건 이상 | `movies.json` 영화 **964편** (한국 영화 168편). 필드 구조는 [01-architecture.md §4.1](01-architecture.md#41-항목-메타데이터-moviesjson) |
| 외부 문서 출처와 이용 조건 | 한국어 위키백과 API(`https://ko.wikipedia.org/w/api.php`), 본문 **CC BY-SA 4.0**. 대비책으로 제공 문서 묶음 `movielab_wiki/` (3,725 파일 · 고유 문서 2,661건, 2026-09 스냅샷). 이용 조건은 §6 |
| 근거가 필요한 질문 3개 이상 | §3 대표 질문 6개. 작품 밖 지식(과학 · 역사 · 원작)이 있어야 답할 수 있다 |
| 위험 도메인 여부 | 영화는 건강 · 금융처럼 판단이 위험한 도메인이 **아니다**. 면책 문구는 표시하지 않는다. 표시 기능 자체는 구현하고 테스트한다(SPEC-F2012, 가정 A-16) |

## 3. 대표 질문

근거 없이 답하면 틀리기 쉬운 질문이다. 검증(4장), NF2001 응답 시간 측정, F2015 RAG 전후 비교에 같은 목록을 쓴다.

|---|---|---|---|---|

## 4. 사용자와 핵심 시나리오

| ID | 시나리오 | 관련 요구사항 |
|---|---|---|
| S1 | 사이드바에서 영화를 고르고 채팅으로 질문한다. 답변에는 `[근거 n]`이 붙고, 답변 아래에 인용된 근거의 출처 유형 · 제목 · 원문 링크가 나온다 | F2001~F2009 |
| S2 | 처음 묻는 질문이면 위키백과에서 문서를 수집 · 색인하는 진행 상태가 보이고, 끝나면 수집한 문서 제목이 표시된다. 같은 질문을 다시 하면 수집 없이 바로 답한다 | F2003~F2005, F2012, NF2002 |
| S3 | 선택한 영화의 **관람 가이드**를 생성하거나, 영화에 관한 주장을 입력해 **사실 여부 판정**을 받는다. 둘 다 근거가 붙는다 | F2010 |
| S4 | "1990년대 한국 스릴러" 같은 조건을 자연어로 입력하면 조건에 맞는 영화만 카드로 나오고, 카드를 누르면 그 영화의 대화로 이어진다 | F2011 |
| S5 | 색인이 없거나 API 키가 없으면 해결 방법이 담긴 안내가 나오고, 오류의 기술 정보는 화면에 나오지 않는다 | F2012, NF2003, NF2004 |

## 5. 범위

| 구분 | 내용 | SPEC 위치 |
|---|---|---|
| **MVP** | 필수 기능 F2001~F2012 + 비기능 NF2001~NF2007. 요구사항 하나에 SPEC 하나(1:1) | `docs/spec/mvp/` |
| **심화** | F2013 프론트엔드 직접 구현, F2014 MMR, F2015 RAG 전후 비교, F2016 여러 문서 출처 결합(위키백과 + PDF) | `docs/spec/advanced/` |
| **확장** | 심화 이후의 추가 기능. 구현 전에 SPEC을 먼저 작성한다 | `docs/spec/extensions/` |
| 범위 밖 | 회원 · 로그인, 대화 기록의 서버 영구 저장, 다국어 UI, 포스터 이미지, 상업적 이용 | — |

필수 기능은 명세서에 따라 수정할 수 없다. SPEC은 표현만 영화 도메인에 맞게 바꾼다(예: "항목" → "영화", "외부 문서" → "위키백과 문서").

## 6. 데이터 출처와 이용 조건 (NF2007)

| 데이터 | 출처 | 이용 조건 | 지키는 방법 |
|---|---|---|---|
| `movies.json` (영화 964편) | TMDB(The Movie Database) 기반, SSAFY 제공 가공본 | TMDB 이용약관. 교육 · 비상업 목적으로만 사용하고 TMDB 출처를 고지한다 (가정 A-15) | README와 화면 하단에 TMDB 출처 고지. 근거 링크로 `tmdb_url` 표시. **공개 저장소에 원본 파일을 커밋하지 않는다** |

## 9. 용어

| 용어 | 뜻 |
|---|---|
| 항목 | 서비스가 다루는 단위. Movie Lab에서는 **영화** |
| 메타 청크 | 영화 1편을 텍스트 1개로 만든 색인 단위 (`movie_meta` 컬렉션) |
| 위키 청크 | 위키백과 문서 본문을 청킹한 조각 (`wiki_docs` 컬렉션) |
| 항목 자체 문서 | 선택한 영화 자체를 다룬 위키백과 문서 (예: 「인터스텔라」, 「미녀와 야수 (2017년 영화)」) |
| 근거(Evidence) | 답변 생성에 넣는 청크 1개. `[근거 n]` 번호, 출처 유형, 제목, 원문 출처를 가진다 |
| 출처 유형 | `영화 메타데이터` · `위키백과` · `PDF` |
| 수집 매니페스트 | 영화별로 이미 검색한 검색어와 수집한 문서를 기록한 파일 (NF2002) |
| live 테스트 | 실제 GMS · 위키백과를 호출하는 테스트. `@pytest.mark.live`. CI에서 실행하지 않는다 |
