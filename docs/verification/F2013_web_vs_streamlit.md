# F2013 웹 화면과 Streamlit 화면 기능 대응표 (TC-F2013-08)

필수 구현(Streamlit, F2009~F2012)과 심화 웹 화면(F2013)의 기능 대응. 두 화면은 같은 `services`를 쓴다.
제출 시 `03_검증결과.md`로 옮긴다. 각 행의 실제 실행 확인(수동)은 화면 캡처 `docs/verification/screenshots/V4.5-1_web*.png`로 남긴다.

| 기능 | Streamlit | 웹 (HTML · CSS · JS) | 차이 |
|---|---|---|---|
| 영화 선택 (F2009) | 사이드바 선택 상자(964편 전체) | 왼쪽 패널 제목 검색 + 결과 목록(`GET /api/movies`, 기본 50건) | 웹은 검색해서 고른다 |
| 질문 · 답변 (F2009) | 채팅 입력, 영화별 대화 기록(`session_state`) | 질문 입력, 영화별 대화 기록(페이지 메모리 + `sessionStorage`) | 없음 |
| 인용 근거 표시 (F2008) | 번호 · 출처 유형 · 제목 · 링크 · 라이선스 + 본문 미리보기 | 번호 · 출처 유형 · 제목 · 원문 링크 · 라이선스 | 웹은 본문 미리보기 없음 |
| 진행 상태 (F2012) | `st.status` 상자에 단계 줄 누적, 수집 상세 | NDJSON 스트림 단계를 한 줄로 갱신, 완료 시 소요 시간 | 웹은 수집 상세(검색어 · 버린 문서) 없음 |
| 키 없음 · 색인 없음 안내 (F2012) | 오류 · 경고 후 정지 / 입력 비활성 | `/api/health` 결과로 배너, 요청 시 503 + 안내 문구 | 웹은 입력을 막지 않고 서버가 거절 |
| 관람 가이드 (F2010) | 버튼 → 마크다운 + 근거 | 버튼 → 텍스트(마크다운 원문) + 근거 | 웹은 마크다운을 렌더링하지 않는다(HTML 주입 방지) |
| 사실 판정 (F2010) | 주장 입력 → 색 배지 판정 + 이유 + 근거 | 주장 입력 → 판정 표시 + 이유 + 근거 | 배지 색 없음 |
| 조건 탐색 (F2011) | 조건 입력 → 카드, "이 영화로 질문하기" | 조건 입력 → 카드, 카드 클릭 시 영화 선택 + 질문하기로 이동 | 없음 |
| 오류 표시 (NF2004) | 안내 문구만, traceback은 로그 | `{"error":{code,message}}`의 문구만, traceback은 로그 | 없음 |
